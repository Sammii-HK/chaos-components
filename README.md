# chaos components

Fun, beautiful and slightly unusable UI experiments by [Sammii](https://sammii.dev): the ones that didn't make it into [Prism](https://prism.sammii.dev).

Each was built with real care (hand-tuned springs, cursor-reactive colour, keyboard and reduced-motion support) and then charged with a crime against usability.

## The accused

| Component | Charge |
| --- | --- |
| Magnetic button | Moving the target: it lunges at your cursor, so you never click where you aimed |
| Fluid tooltip | Loitering: follows the cursor instead of staying by what it describes |
| Shimmer text | Being a screensaver: a light band that sweeps forever |
| Tilt card | Leaning: good content at an angle for no reason |

## Toys

Canvas sketches with no job: gravity wells, fluid mesh, text dissolve and colour field.

## Run it

```bash
npm install
npm run dev
```

Vite, React 19, Tailwind 4. No runtime dependencies beyond React and lucide icons.
